    01 / DEBUGReward 不对，先从哪里查？＋

    先检查生成文本、checkpoint 加载和 chat template。保存一轮 rollout，用固定 batch 重放训练，再比较 log-prob，最后才调整算法。

    Debug 与重放 →理解训推差异 →
    02 / PROFILE训练太慢，时间究竟花在哪里？＋

    区分 rollout、reward、权重传输和训练耗时。先用 trace 找关键路径，再 profile 瓶颈引擎。使用 tools/profile_rollout.py 收集 SGLang trace，观察 prefill / decode。

    性能剖析 →时间线与追踪 →指标与观测 →
    03 / SCALE如何从一台机器走向多个集群？＋

    先划分 GPU 的归属，再根据网络选择权重传输。Prefill / decode 资源需求不同时考虑 PD；需要恢复长任务时接入持久 rollout 存储。

    External engines →Delta sync →Partial / distributed async →straw →故障恢复 →
    04 / EXTEND我的 Agent，需要自己的环境。＋

    从自定义逐样本生成函数和奖励开始。需要改变数据调度或跨 step 状态时，再替换完整 rollout 编排。

    Agent RL →扩展接口 →SGLang topology →
