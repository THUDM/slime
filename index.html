    04 / WHEN YOU WANT TO GO FURTHER

    A good experiment asks good questions.

    Open a question. Find the next measurement, then the right tool.

    01 / DEBUGThe reward looks wrong. Where do I start?＋

    Inspect generated text, checkpoint loading, and the chat template first. Save a rollout, replay a fixed batch on the training side, then compare log-probs before changing the algorithm.

    Debug & replay →Understand mismatch →
    02 / PROFILETraining is slow. What am I waiting for?＋

    Separate rollout, reward, weight transfer, and training time. Trace the critical path, then profile the busy engine. Use tools/profile_rollout.py to collect SGLang traces and inspect prefill/decode behavior.

    Profiling →Timeline & tracing →Metrics →
    03 / SCALEHow do I grow beyond one cluster?＋

    Split GPU ownership, then choose a weight transport that matches the network. Add PD when prefill and decode need different resources; use persistent rollout storage when jobs need recovery.

    External engines →Delta sync →Partial / distributed async →straw →Recovery →
    04 / EXTENDMy agent needs its own world.＋

    Start with a custom per-sample generation function and reward. Replace rollout orchestration only when your data scheduling or cross-step state needs it.

    Agent RL →Extension interfaces →SGLang topology →
